## 2. UI / State / Logic / Storage — האם יש הפרדה?

| שכבה | קיימת? | ראיה |
| --- | --- | --- |
| **UI** | מעורבב | `hm-tests.js` — `renderRow()` בונה HTML *וגם* קורא ל-`scoreOne()` |
| **State** | ❌ אין | אין store. המצב הוא משתני closure + `LS` ישירות |
| **Business Logic** | ✅ חלקית | הניקוד מרוכז ב-`hm-tests.js` ו**אינו משוכפל** (‎10‎ מופעים שם, ‎0‎ באחרים) |

| **Sync** | 🟡 חלקי | קיים לשיאים בלבד |

**מסקנה:** ההפרדה היחידה שהחזיקה היא `LS`. **אין גבול בין DOM ללוגיקה** — כל מודול מצייר ומחשב באותה פונקציה. זו החוב הארכיטקטוני המרכזי, אבל **הוא לא דחוף** כי הוא לא מאבד נתונים.

## 5. Storage & Offline

### מפה מלאה — ‎60‎ מפתחות ב-`localStorage`
`bk.* bt.* ft.* grades.* hx.* lb.* ls.* pf.* rec.* settings stu.* tools.*`

| מנגנון | מה יש בו | מגובה? |
| --- | --- | --- |
| `localStorage` | כל הנתונים התפעוליים | ✅ |
| `IndexedDB` `pehub-records` | **סרטוני שיאים** | 🔴 **לא** |
| `sessionStorage` | תפקיד + מצב נעילה | ✅ לא נדרש |
| Cache API | קליפת האפליקציה | ✅ לא נדרש |

### 🔴 חריגת מכסה — `hm-app.js:10`
```js
set(k,v){try{localStorage.setItem("pehub."+k,JSON.stringify(v))}catch(e){}}
```
**`catch` ריק.** אין `QuotaExceededError` בשום מקום בקוד (אומת: ‎0‎ מופעים).

**חישוב:** ‎300‎ תלמידים × ‎30‎ מבחנים × ‎3‎ ניסיונות ≈ ‎27,000‎ רשומות × ~‎180‎ בתים ≈ **‎4.8MB‎**.
מכסה טיפוסית: **‎5MB‎**. **זה גבול שמורה פעיל יגיע אליו, לא תרחיש תיאורטי.**

### תשובות לשאלות שנשאלו

| שאלה | תשובה |
| --- | --- |
| מה עובד offline? | **הכול.** נבדק בניתוק רשת מלא: נעילה, ‎30‎ מבחנים, ביפ, שיעור |
| מה לא עובד offline? | סנכרון שיאים · גופני Google בטעינה ראשונה · טופס דרייב |
| מחיקת נתוני דפדפן? | **הכול נמחק.** אין התרעה, אין שחזור |
| החלפת מכשיר? | גיבוי ידני בלבד — **וללא סרטוני השיאים** |
| טלפון + מחשב? | ❌ **לא נתמך.** אין סנכרון לנתוני הליבה |

## 6. Backup / Encryption

**IMPLEMENTED.** `hm-app.js:356–475`

| רכיב | ערך | ראיה |
| --- | --- | --- |
| KDF | PBKDF2-SHA256, **‎310,000‎** סבבים | `hm-app.js:369,380` |
| הצפנה | AES-GCM-256 | `hm-app.js:381,388` |
| מלח / IV | ‎16‎ / ‎12‎ בתים אקראיים לכל קובץ | `hm-app.js:384–385` |
| אחסון סיסמה | **אין** — אומת, אפס כתיבות | — |

### מה זה **לא** נותן
- ❌ **כבוי כברירת מחדל** (`bk.enc` = `false`) — ברירת המחדל היא JSON גלוי
- ❌ **לא מגבה IndexedDB** — סרטוני השיאים אובדים
- ❌ אין גרסאות סכמה מעבר ל-`v:1`; אין נתיב הגירה מוגדר
- ❌ אין הגנה מפני brute-force מעבר ל-‎3‎ ניסיונות ב-UI (הקובץ עצמו חשוף)

**הערכה טכנית:** המימוש **תקני ונכון**. הפער הוא ב**היקף** ובברירת המחדל, לא באלגוריתם. **אין כאן אישור אבטחה — יש הצהרה על מה שנבדק.**

## 11. Security / Privacy — Technical Assessment

> **אין כאן חוות דעת משפטית.** זו הערכה טכנית של מה שנבדק בקוד.

| בדיקה | ממצא |
| --- | --- |
| PII | שם + כיתה + מין + גיל. **אין ת״ז** — מזעור אמיתי |
| שליחה החוצה | **רק** סנכרון השיאים, ורק אם המורה הזין URL בעצמו |
| Analytics / צד ג׳ | ✅ **אין** |
| AI / LLM | ✅ **אין**. «פרשן המירוץ» הוא מנוע תבניות מקומי |
| תלות CDN | 🟡 `unpkg.com` (React דרך `support.js`) + Google Fonts |
| אימות | ❌ אין. `rec.pass` הוא **קוד ‎4‎ ספרות ב-localStorage בטקסט גלוי** |
| הרשאות | 🟡 מורה/תלמיד ב-`sessionStorage` — **ניתן לעקיפה מ-DevTools** |

**נקודות חולשה מפורשות:**
1. קוד המורה אינו מוצפן ואינו hashed
2. מצב תלמיד הוא הסתרת UI, לא הרשאה
3. `support.js` טוען React מ-unpkg — **תלות חיצונית שאינה נחוצה** (האפליקציה עולה בלעדיה דרך fallback)
