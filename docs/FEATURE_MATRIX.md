## סיכום

| סיווג | כמות | הערה |
| --- | --- | --- |
| **CORE** | ‎11‎ | מדידה + מעקב + תשתית — **המוצר האמיתי** |
| **SUPPORT** | ‎17‎ | מחזקים את הליבה |
| **SECONDARY** | ‎5‎ | ערך אמיתי, שוק צר |
| **FUTURE** | ‎3‎ | תלויים בתיקון C1 |
| **DEPRIORITIZE** | ‎4‎ | תחזוקה בלי בידול |
| **REMOVE** | **‎0‎** | — |

**למה אפס REMOVE:** שום פיצ׳ר אינו מזיק. גם המועמדים ל-DEPRIORITIZE נותנים ערך למישהו. ההמלצה היא **להסתיר ולהפסיק להשקיע**, לא למחוק — מחיקה מסכנת משתמשים קיימים בלי להרוויח דבר.

> **כלל שהנחה את הסיווג:** פיצ׳ר הוא CORE אם הוא **מזין את שרשרת הנתונים** או **מוציא ממנה ערך**. כל השאר הוא לכל היותר SUPPORT.
