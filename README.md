ערכת שטח למורה לחינוך גופני — אפליקציית דפדפן אחת, בלי התקנה ובלי שרת.
כל הנתונים נשמרים במכשיר בלבד (localStorage + IndexedDB לסרטונים) — שום דבר לא נשלח לשום שרת.

## 🏆 איך עובדים השיאים — ההסבר המלא

זו המערכת שדרכה תלמידים משתתפים באפליקציה. היא בנויה כך שלתלמיד **אין גישה לשום דבר חוץ מצפייה בשיאים והעלאת שיא**.

### שני מצבי כניסה

במסך הפתיחה יש שני כפתורים:

| | **כניסת מורה** | **כניסת תלמיד** |
| --- | --- | --- |
| דורש קוד | ✅ כן (ברירת מחדל `1234`) | ❌ לא |
| מודולים נגישים | כל העשרה | **שניים בלבד**: אלופי בית הספר + משחקים |
| הגדרות (⚙) | ✅ | ❌ מוסתר |
| לוח מורה 🔐 | ✅ | ❌ מוסתר |
| מצב טלוויזיה | ✅ | ❌ מוסתר |
| צפייה בלוח השיאים | ✅ | ✅ |
| צפייה בסרטוני הוכחה | ✅ | ✅ |
| שליחת שיא חדש | ✅ | ✅ |
| **אישור / עריכה / מחיקה של שיא** | ✅ | ❌ |
| נתוני תלמידים, מבחנים, גיבויים | ✅ | ❌ |

מצב תלמיד נאכף בשלוש שכבות: כפתורי הניווט מוסתרים, הראוטר מחזיר לתלמיד ללוח השיאים גם אם ינסה לשנות את כתובת ה־URL ידנית (`#stu` → `#rec`), והכפתורים הרגישים מוסתרים מה־DOM.

**מסירת המכשיר לכיתה:** בלוח השיאים יש כפתור `📱 מסור לתלמידים`. לחיצה עליו מעבירה את המכשיר למצב תלמיד באמצע השיעור. היציאה חזרה למצב מורה דורשת את קוד המורה.

> ⚠️ זו הגנה ברמת ממשק, לא הצפנה. היא מיועדת למנוע מתלמיד לשחק עם המכשיר בשיעור — לא לעמוד מול מישהו שפותח כלי פיתוח בדפדפן. הנתונים ממילא יושבים רק על המכשיר הזה.

### מסלול חיי השיא

```
תלמיד בוחר ענף
   └─> 🎬 "שלח שיא חדש" — שם, כיתה, תוצאה, סרטון הוכחה
        └─> נשמר ב-IndexedDB עם status: "pending"
             └─> מופיע כמונה אדום על כפתור "לוח מורה"
                  └─> המורה נכנס עם קוד, צופה בסרטון
                       ├─> ✓ אישור  → status: "approved" → עולה ללוח + קונפטי + צופר
                       └─> ✕ דחייה → נמחק לגמרי
```

**שיא שלא אושר לא מופיע בשום מקום** — לא בלוח, לא באריחי הענפים, לא במצב הטלוויזיה ולא במונה בדף הבית. רק המורה רואה אותו, ורק בלוח המורה.

### נגן ביקורת השיא

כשהמורה לוחץ ▶ על סרטון הוכחה נפתח נגן עם **האטה (0.25× / 0.5× / 1× / 2×), צעד פריים־פריים ולולאה אוטומטית** — כדי לספור חזרות ולוודא טכניקה לפני אישור. הסרטון נשמר ב-IndexedDB במכשיר בלבד, עד 120MB לסרטון.

### הוספה ידנית (מורה בלבד)

מדדת בשטח ואין סרטון? בלוח המורה: `➕ הוסף שיא ידנית` → שם, כיתה, ענף, תוצאה. השיא נכנס ללוח **מיד כמאושר**, מסומן כ־«ידני», ואפשר לערוך או למחוק אותו בכל רגע מטבלת «כל השיאים המאושרים».

### ענפים

20 ענפי ברירת מחדל (קפיצה בחבל, שכיבות סמיכה, מתח, בטן, פלאנק, קפיצה למרחק, 60 מ׳, 100 מ׳, 1000 מ׳, סקוואטים, עונשין, ביפ טסט, קפיצה לגובה, ברפי, מקבילים, כיסא קיר, נגיחות, מעבורת 4×10, כדור מדיסין, גמישות).

בלוח המורה אפשר להוסיף **ענפים משלך** — סמל, שם, יחידת מדידה, ואם נמוך יותר = טוב יותר (למשל זמן). ענף מותאם מתנהג בדיוק כמו ענף רגיל, כולל דירוג, השוואות וסרטונים.

### דירוג והשוואות

- **דירוג** — לפי `lower`: בענפי זמן (60 מ׳, מעבורת) הנמוך מנצח; בשאר הגבוה מנצח.
- **שיא בית הספר** = התוצאה המאושרת הטובה ביותר בענף.
- **שיא ישראל / שיא העולם** = ערכי ייחוס שהמורה עורך בעצמו בלוח המורה. הם קובעים את אורך העמודות במסך ההשוואה — שיא בית הספר מוצג כאחוז משיא העולם.
- **מצב טלוויזיה** 📺 — מחזור אוטומטי בין ענפים כל 9 שניות, שלושת המקומות הראשונים וסרטון המקום הראשון מתנגן ברקע. מיועד למסך בכניסה לבית הספר.

### גיבוי

`⬇ גיבוי JSON` מייצא את כל השיאים וערכי הייחוס — **בלי הסרטונים** (הם גדולים מדי ל-JSON, ומסומנים ב־`hadVideo`). השחזור מחזיר את הרשומות בלי הסרטונים. הסרטונים עצמם חיים רק במכשיר שבו צולמו.

## 🔗 איך נותנים לתלמידים גישה רק לשיאים

בלוח השיאים יש כפתור `🔗 קישור / QR` שמייצר קישור וברקוד. יש **שני מצבים שונים לגמרי** — חשוב לבחור נכון:

### מצב א׳ — עמדה / טאבלט של בית הספר (אותו מכשיר)

```
https://<כתובת-האפליקציה>/?role=student#rec
```

הקישור פותח את האפליקציה ישר במצב תלמיד, **בלי מסך הקוד**. אפשר לשמור אותו כסימנייה על טאבלט בחדר הכושר, או לתלות את הברקוד על הקיר.

השיא נשמר במכשיר הזה ונכנס לתור האישור שלך. זה המצב הפשוט והמומלץ.

### מצב ב׳ — המכשיר האישי של התלמיד

```
https://<כתובת-האפליקציה>/?role=student&guest=1#rec
```

כאן יש מגבלה אמיתית שחייבים להבין: **לאפליקציה אין שרת.** כל הנתונים יושבים ב-localStorage וב-IndexedDB של הדפדפן שבו היא פתוחה. אם תלמיד ישלח שיא מהטלפון שלו, הוא יישמר בטלפון שלו — ואתה לעולם לא תראה אותו.

הפתרון: במצב אורח, אחרי שליחת שיא האפליקציה **אורזת אותו לקובץ `.hmrec`** (מטא־דאטה + הסרטון) ומציעה לשלוח אותו. בנייד זה נפתח ישירות בתפריט השיתוף (וואטסאפ / מייל); במחשב הקובץ פשוט יורד.

אצלך: לוח המורה ← `📥 קלוט שיא מקובץ` ← הקובץ נכנס לתור האישור עם הסרטון, בדיוק כמו שיא רגיל. יש הגנה מפני קליטה כפולה של אותו קובץ.

בדף הענף התלמיד רואה את מה ששלח מהמכשיר שלו, עם כפתור `📤 שלח למורה שוב` — למקרה שהשליחה נכשלה.

## 📚 מאגר הידע והמקורות

הקישורים במאגר מפנים לעמודים ולמסמכים הרשמיים החיים. **האפליקציה לא מושכת מהם תוכן אוטומטית** — היא לא יכולה: אתרי משרד החינוך ו-WHO חוסמים גישה ישירה מדפדפן (CORS), והאפליקציה בנויה לעבוד אופליין. במקום זה כל פריט הוא תקציר עבודה שנכתב מול המקור, עם קישור ישיר אליו. המסמך המחייב הוא תמיד המקור.

**מקורות שכלולים:**

- 🇮🇱 **משרד החינוך — המרחב הפדגוגי**: תוכניות לימודים לחטיבת ביניים ולחטיבה עליונה, הערכה בחינוך גופני מעשי, חוברת משחקי פנאי ונופש, משחקי כדור קבוצתיים, למידה מקוונת, מעגל השנה.
- 🌍 **ארגון הבריאות העולמי (WHO)**: הנחיות פעילות גופנית והתנהגות יושבנית 2020 + סיכום הראיות.
- 🇺🇸 **CDC**: הנחיות פעילות גופנית לילדים בגיל בית ספר.
- 🇬🇧 **Chief Medical Officers**: הנחיות הפעילות הגופנית של רופאי המדינה בבריטניה.
- 📏 **SHAPE America**: הסטנדרטים הלאומיים לחינוך גופני (מהדורת 2024) — כל מערך שיעור באפליקציה ממופה לארבעת הסטנדרטים האלה.
- 📏 **Cooper Institute**: FITNESSGRAM® ואזור הכושר הבריא — הבסיס לנורמות בביפ טסט ובמעקב התלמידים.
- 🏋️ **NSCA**: נייר עמדה על אימוני התנגדות לילדים ובני נוער.
- ⚽ **מחקר עמיתים**: יעילות תוכנית החימום 11+ במניעת פציעות.

**12 תוכניות אימון מוערכות** מוכנות להפעלה, כל אחת עם: למי מיועדת, על מה נשענת, מינון, מבנה מלא ודגשי הוראה — חימום 11+, HIIT לכיתה, כוח בסיסי לנוער, מחזור הכנה לביפ (6 שבועות), מסלול ליבה (8 שבועות), מהירות וזריזות, יחידת הוראה במשחק כדור, שיעור מכיל, יום גשום, ניהול עומס, אקלים מוטיבציוני, גמישות וניידות.

## 🎮 דף המשחקים

**מטרה · למי מתאים · מהלך מלא שלב־שלב · וריאציות והתאמות · דגשי בטיחות · קישור לצפייה · כפתור «קח למערך שיעור»**

הקישור לצפייה פותח **חיפוש יוטיוב** לפי שם המשחק ולא סרטון ספציפי — בכוונה. סרטון בודד נמחק או נחסם עם הזמן והקישור נשבר; חיפוש תמיד עובד, ומאפשר לבחור סרטון בעברית או באנגלית לפי מה שמתאים לכיתה.

הקטגוריות מבוססות על חלוקת חוברת משחקי הפנאי והנופש של הפיקוח על החינוך הגופני (מקושרת במאגר הידע).

## 📋 מחולל מערכי השיעור

בוחרים: **שכבה · אורך · מספר תלמידים · מקום · נושא · ציוד זמין** — ולוחצים «בנה מערך בשניות».

21 נושאים בשש קבוצות: כושר גופני (אירובי, כוח, ליבה, מהירות, גמישות) · משחקי כדור (כדורסל, כדורעף, כדוריד, כדורגל, ענפים חלופיים) · אתלטיקה (ריצות, קפיצות והטלות) · התעמלות ותנועה (אקרובטיקה, ריקוד) · מבחנים ומדידה (הכנה לביפ, שיעור מבחן) · בריאות וחברה (תזונה, גיבוש, משחק, יום גשום, שיעור מכיל).

**מה יוצא:** מטרות · מיפוי לארבעת סטנדרטים SHAPE · ציוד · מהלך מלא לפי דקות · התאמות במודל STEP (מתקשה / מתקדם / פטור) · מה מסתכלים עליו בהערכה מעצבת · בטיחות · משימה להמשך · עוגן מקצועי עם קישור למקור.

כל נושא מכיל שתי גרסאות לחטיבה ושתיים לתיכון, וחימום/סיום נבחרים אקראית — `🎲 גרסה אחרת` מייצר מערך שונה לאותו נושא. `🖨 הדפס` מפיק דף מוכן להגשה, ו-`💾 שמור` שולח לספריית המערכים.

## 📷 שיפורים בפוטו־פיניש

אחרי סקירה של פרויקטי קוד פתוח בתחום ([OpenPhotoFinish](https://github.com/artmyb/OpenPhotoFinish), [photo-finish](https://github.com/jorel13/photo-finish)) ושל האופן שבו מערכות FAT מסחריות עובדות, נוספו:

- **קיזוז מרחק המזניק.** הקול נע ‎343‎ מ/ש. אם הטלפון עומד ‎20‎ מ׳ מהאקדח, השמע מגיע באיחור של ‎58‎ מ״ש והשעון היה מתחיל מאוחר מדי. הזנת המרחק בשדה החדש מזיזה את זמן ההתחלה אחורה בהתאם — בדיוק הקיזוז שמערכות FAT מבצעות.
- **אינטרפולציה תת־עמודתית.** קריאת הזמן ברצועת הסיום הייתה מתיישרת לעמודה הקרובה, כלומר קוונטיזציה של פריים שלם. עכשיו הזמן מחושב ליניארית בין שתי העמודות שמקיפות את נקודת הלחיצה — רזולוציה טובה יותר מקצב הפריימים של המצלמה.
- **חיווי דיוק אמיתי.** מסך «תמונת סיום» מציג את קצב הדגימה שהושג בפועל ואת רזולוציית הזמן הנובעת ממנו (למשל ‎±17‎ מ״ש), במקום להשאיר את המורה לנחש.
- **הדבקת רשימת מתחרים.** כפתור «הדבק רשימה» מקבל שמות משורות או מופרדים בפסיקים ומגדיר מסלולים אוטומטית — במקום להקליד שם־שם.

## הפעלה

```bash
# כל שרת סטטי:
python3 -m http.server 8000
# ואז http://localhost:8000
```

או פשוט לפתוח את **`Hamegrash.html`** — קובץ יחיד שעובד בלחיצה כפולה, בלי שרת ובלי אינטרנט.

לבנייה מחדש של הקובץ היחיד אחרי שינוי בקוד:

```bash
node build-standalone.js
```

## מבנה

| קובץ | תפקיד |
| --- | --- |
| `index.html` | הממשק המלא (כל המסכים) |
| `hm-app.js` | ליבה, ראוטר, הרשאות + מודולי ביפ / פוטו־פיניש / שיאים / כושר |
| `hm-know.js` | מאגר הידע והמקורות + דף המשחקים |
| `hm-tools.js` | כלי כיתה: קבוצות, הגרלה, נוכחות, מחוונים |
| `hm-qr.js` | מקודד QR עצמאי (מצב בייטים, רמת תיקון M) |
| `hm-lesson.js` | מחולל מערכי השיעור |
| `hm-new.js` | תלמידים / תזונה / מסך כניסה ותוספות בית |
| `hm-styles.css` | עיצוב |
| `support.js` | ריצת הרכיב (לגרסת `index.html`) |
| `build-standalone.js` | בונה את `Hamegrash.html` |
| `Hamegrash.html` | קובץ יחיד אופליין — נבנה, לא נערך ידנית |

## הערות

- קוד כניסה ברירת מחדל: `1234`. ניתן לשינוי בלוח המורה, ואפשר לכבות את הנעילה בהגדרות.
- כל הנתונים נשמרים מקומית במכשיר. אין שרת, אין חשבון, אין שליחה החוצה.
- `index.html` טוען ריצת רכיב שמושכת ספרייה מהרשת. אם אין אינטרנט, מנגנון גיבוי מפעיל את האפליקציה ישירות אחרי 1.2 שניות — כך היא עובדת גם אופליין. `Hamegrash.html` לא תלוי בזה כלל.
- דורש דפדפן מודרני. מצלמה ומיקרופון דורשים HTTPS או localhost.
