# המגרש PRO

ערכת שטח למורה לחינוך גופני — אפליקציית דפדפן אחת, בלי התקנה ובלי שרת.

## מודולים
- **שיעור מלא** — בניית מערך לפי שכבה (ז׳–ט׳ / י׳–י״ב), מטרה ואורך; הפעלה עם כריזה קולית, שמירה לספרייה והדפסה.
- **ביפ טסט** — פרוטוקול Léger, ביפים על שעון Web Audio, VO₂max ונורמות FITNESSGRAM®.
- **פוטו־פיניש** — מדידת זמנים מהמצלמה, זיהוי חציית קו, הקפות, תעודות ו-CSV.
- **אלופי בית הספר** — לוח שיאים עם סרטוני הוכחה (IndexedDB), אישור מורה ומצב טלוויזיה.
- **מאמן כושר** — טיימר אינטרוולים, מחולל תחנות, ספריית תרגילים וקוביית כושר.
- **התלמידים שלי** — מעקב אישי, גרף בין־מבחני, BMI ואיתור מי מתחת לנורמה.
- **פינת תזונה** — טיפ יומי לכיתה ומדריך לפי נושאים.

## הפעלה
```
# כל שרת סטטי, למשל:
python3 -m http.server 8000
# ואז http://localhost:8000
```
או פשוט לפתוח את `HaMigrash-PRO-standalone.html` — קובץ יחיד שעובד אופליין בלחיצה כפולה.

## מבנה
| קובץ | תפקיד |
| --- | --- |
| `index.html` | הממשק המלא (כל המסכים) |
| `hm-app.js` | ליבה + מודולי ביפ / פוטו־פיניש / שיאים / כושר |
| `hm-new.js` | תלמידים / שיעור מלא / תזונה / נעילת מורה |
| `hm-styles.css` | עיצוב |
| `support.js` | ריצת הרכיב |

## הערות
- קוד כניסה ברירת מחדל: `1234` (ניתן לשינוי בלוח המורה; אפשר לכבות נעילה בהגדרות).
- כל הנתונים נשמרים מקומית במכשיר (localStorage + IndexedDB לסרטונים) — לא נשלח דבר לשרת.
- דורש דפדפן מודרני; מצלמה/מיקרופון דורשים HTTPS או localhost.
