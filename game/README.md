# BrawlZ: Cursed Arenas — מצב הפרויקט

משחק זירה בדפדפן (בראול־לייק), עברית RTL. שתי חזיתות תצוגה מעל ליבת חוקים אחת.

> **למה התיקייה הזו קיימת:** קוד המשחק חי עד עכשיו רק בתוך קונטיינר של סשן,
> ולא היה בשום ריפו. הקונטיינר נמחק. מה שיש כאן שוחזר מתוך שני העמודים
> שפורסמו כ־Artifacts, שהם קבצים עצמאיים שכוללים הכול. **מעכשיו זה בגיט.**

## איפה אנחנו — MVP הושלם

מפת הדרכים הקודמת (`CHAOS//CORE — מיפוי הפרויקט`) הגדירה חמישה סעיפי MVP.
בדקתי אותם מול הבילד שרץ בפועל — **כולם קיימים**:

| סעיף MVP | מצב | איפה זה נראה |
|---|---|---|
| לולאת מאץ׳ — טיימר, ניצחון, מסך סיום | ✅ | שעון `2:00`, ניקוד, ספירה לאחור, מסך תוצאה |
| צינור מודיפיקטורים ב־`CombatActor` | ✅ | `src/core/combat.js` |
| שלושה Cores שמשנים סגנון | ✅ | אש · כבידה · צל (+ "ללא ליבה" כבסיס) |
| שמירה מקומית | ✅ | `localStorage` — שיא ודמות אחרונה |
| סאונד בסיסי | ✅ | `AudioContext`, כפתור השתקה ב־HUD |

**V1 עדיין לא התחיל** — אין ולו אזכור אחד של `fusion` או `chaos` בקוד.

תוכן קיים: **6 דמויות · 4 זירות · 4 ליבות**. גרסת תצוגה `Beta 0.3`.

## מה שוחזר, ומה אבד

| רכיב | מצב | הערה |
|---|---|---|
| `src/core/combat.js` | ✅ מקור קריא | הנכס החשוב בפרויקט. 25KB עם הערות מלאות |
| `src/core/arena-layout.js` | ✅ מקור קריא | מקור האמת לגריד, משותף לשתי החזיתות |
| `src/game/*` (שכבת Phaser, 8 מודולים) | ✅ מקור קריא | הבילד הדו־ממדי הגיע לא־ממוזער |
| `data/*.json` | ✅ שוחזר במלואו | לפי נתיבי הקבצים המקוריים |
| `assets/*.png` | ✅ 12 טקסטורות | רצפה/קיר/שיח × 4 זירות, 512×512 |
| `src/three/` (10 קבצים, 2495 שורות) | ⚠️ **ממוזער בלבד** | `BUNDLE.min.js` — רץ מצוין, אבל לא ניתן לעריכה |
| `tools/` (7 כלי צנרת ארט) | ❌ אבד | |
| `unity/` (מראה C# של הליבה) | ❌ אבד | מוזכר בהערות `combat.js` |

**המשמעות המעשית:** אפשר להמשיך לפתח את *החוקים* מיד — הם קריאים. שכבת
התלת־ממד תצטרך להיכתב מחדש כשנרצה לשנות בה משהו, או שנמשיך להוסיף מעליה.
זו בדיוק הסיבה שההפרדה בין חוקים לתצוגה שווה משהו: מה שאבד הוא הזול לכתוב מחדש.

## מבנה

```
game/
├── dist/            שני בילדים עצמאיים ומשוחקים — פותחים ישירות בדפדפן
│   ├── brawlz-3d.html   ← הגרסה הפעילה
│   └── brawlz-2d.html   ← ארכיון עובד (Phaser), מוקפא בכוונה
├── src/core/        חוקי המשחק. אפס תלות במנוע תצוגה
├── src/game/        שכבת Phaser — מקור מלא
├── src/three/       שכבת התלת־ממד — ממוזער בלבד
├── data/            דמויות, זירות, ליבות
└── assets/          טקסטורות זירה
```

## הרצה

```
# הבילדים ב-dist/ עצמאיים — פשוט לפתוח בדפדפן, בלי שרת ובלי התקנה
xdg-open dist/brawlz-3d.html
```

עבודה על המקור המפוצל (`src/`, `data/`) דורשת שרת מקומי, כי הנתונים נטענים
ב־`fetch`: `python3 -m http.server` ואז לפתוח את הכתובת המקומית.

## אומת

הבילד התלת־ממדי נבדק ב־Chromium בסשן הזה: התפריט נטען (4 זירות, 4 ליבות,
6 דמויות), מאץ׳ נפתח, שעון וניקוד ו־HUD פעילים, הזירה מרונדרת — **אפס שגיאות
קונסול**. כל קובצי המקור וה־JSON עוברים בדיקת תחביר.

## הצעד הבא

V1 לפי המפה: **Core Fusion** (שילוב שתי ליבות) ו־**Chaos Rules** (הרחבת מנהל
המפגעים לחוקי מאץ׳). שניהם חוקים טהורים — כלומר שניהם נכנסים ב־`src/core/`,
שהוא בדיוק החלק ששרד קריא.
