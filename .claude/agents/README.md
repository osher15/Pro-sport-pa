## איך משתמשים

בשיחה: *"תפעיל את brawlz-playtester לבדוק את האיזון של ליבת הצל"*

או פשוט לתאר את הבעיה — הבחירה תיפול לפי ה-`description` של כל אחד.

## איך מעדכנים

כל קובץ כאן הוא Markdown רגיל עם כותרת YAML. ערוך חופשי:

- **`description`** — קובע מתי המומחה נבחר אוטומטית. שנה אותו כדי לכוון.
- **גוף המסמך** — ההוראות שהוא מקבל. הוסף כללים, דעות, טעויות שראית.
- **`model`** — `opus` לעבודה מורכבת, `sonnet` למשימות פשוטות ומהירות.
- **`tools`** — השמט כדי לתת הכל, או פרט כדי להגביל (כמו ב-`brawlz-scout`).

**הכי שימושי לעדכן:** אחרי כל פעם שמומחה טעה, כתוב את הטעות בגוף המסמך שלו.
ככה הוא לא יחזור עליה.

## הקשר משותף

כל מומחה קורא גם:
- `brawlz/CLAUDE.md` — כללי הברזל (נטען אוטומטית)
- `brawlz/docs/STATE.md` — איפה אנחנו והמספרים הנוכחיים
- `brawlz/docs/DECISIONS.md` — למה הקוד נראה כמו שהוא נראה
